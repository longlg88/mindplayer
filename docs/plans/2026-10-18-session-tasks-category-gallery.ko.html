연결은 분류나 실행 상태를 바꾸지 않음

하나의 할 일에 여러 세션, 하나의 세션에 여러 할 일을 연결합니다. 연결해도 카테고리는 그대로이며, 응답이 끝나도 할 일이 자동 완료되지는 않습니다. 실제 세션 실행·프롬프트 전송·계정 변경은 없습니다.

설계 범위 · 조작 · 근거

최신 요청의 “세로로 반”은 세로 경계선으로 나눈 좌우 50:50으로 해석했습니다. 제안 대상은 세션 목록 화면이며, 실행 중 pane에 새 패널을 붙이는 안이 아닙니다. 20안 모두 미승인 제안이고, 키는 HTML 시안에서만 유효합니다.

A의 F6는 좌우 목록의 포커스만 바꿉니다. 기존 좌우 방향키의 트리 접기/펼치기 의미를 덮지 않으며, Tab은 브라우저 탐색으로 빠져나갑니다. F7은 연결 추가/해제, 오른쪽 Space는 수동 할 일 완료입니다. Enter는 재개 안내만 보여주며 프로세스를 만들지 않습니다.

B의 T → 목적지 선택 → Enter 미리보기 → Enter 반영, F8 되돌림, G 위치 찾기는 비교용 공통 시연입니다. 이동 내역은 안정적인 세션 ID와 출발/도착 카테고리로 유지하고, 같은 제목의 다른 세션을 건드리지 않습니다. 기존 l은 트리 펼치기, u는 계정 기능으로 유지합니다. F6/F7/F8은 미승인 시연 키이며 Mac에서는 Fn이 필요할 수 있습니다. 저장 방식·재시작 이후 복구·파생 세션 범위는 실제 구현 전에 검증해야 합니다.

빈 업무 목록·삭제된 연결 대상·저장 실패·충돌은 실제 구현의 필수 상태입니다. 이 파일의 합성 연결 데이터는 메모리에만 있고 새로고침하면 초기화됩니다. 기존 카테고리에는 동료 세션 맥락 동기화 설정이 있어 이동이 단순 표시 변경에 그치지 않을 수 있습니다. 확인창의 설정은 합성 예시이며 이 HTML은 동기화를 하지 않습니다. 되돌림은 소속 복원이지 이미 공유한 맥락의 회수가 아닙니다. 운영 알림·마감 연동·AI 자동 분류·실제 터미널 렌더링·스크린리더 호환은 검증하지 않았습니다.

  • 로컬 근거: ui.rs, app/session_list.rs, main.rs, DESIGN.md. 실제 사용자 대화·계정은 읽지 않았습니다.
  • 공개 패턴 1차: tmux choose-tree의 탐색/미리보기, fzf preview의 선택 항목과 연관 정보. 그대로 설치하거나 동작을 복제했다는 뜻은 아닙니다.
  • 공개 패턴 2차: W3C 현재 위치, 확인·되돌림. 이해를 돕는 참고이며 접근성 인증이나 모든 작업의 확인창 의무를 주장하지 않습니다.

렌더링 비교: 정적 스크린샷은 조작 비교가 안 되고, 웹 폼 모형은 터미널 제약을 가립니다. 선택한 방식은 외부 의존성 없는 HTML 문자 격자와 로컬 키보드 시연입니다. 좁은 브라우저에서는 터미널 내부만 가로 스크롤하며 좌우 1:1 비율은 유지합니다.
