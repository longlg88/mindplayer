기능 화면 열어보기

도구는 에이전트가 호출하는 실행 수단이고, 스킬은 필요할 때 읽는 작업 지침입니다. 명령은 사용자가 기능에 들어가는 방법이며, 에이전트는 위임받은 작업을 수행합니다. 예시 스킬·작업자와 아래 상호작용은 실제 실행이 아닙니다.

합성 실행 예시
요청 → 탐색 → 작업자 → 검증 → 응답

실행 가능한 제품이 아닌 UI 시안입니다. 표시된 대화·스킬·도구 결과·작업자·모델·계정과 사용량은 합성 예시입니다. 선택과 입력은 화면에만 반영되며 전송하거나 도구를 실행하지 않습니다. OMP를 여는 대신 MindPlayer에 유사한 흐름을 만드는 제안이며, 실제 Codex 인증·구독 사용과 도구 권한, 세션 연결 및 기능 구현은 별도로 필요합니다.

OMP에서 참고한 실제 화면과 코드

네트워크를 차단한 OMP 18.12.6에서 합성 세션과 임시 스킬로 대화, 슬래시 자동완성, 스킬 검색, /tools, Agent Hub, /model, /effort, /tree, /plan 화면을 직접 확인했습니다. Flow 이름과 MindPlayer 외곽·도구 설명은 제안이며, 설정과 테마에 따라 실제 OMP 화면과 활성 기능은 다릅니다. 좁은 터미널에서 OMP는 Agent Hub의 roster와 inspector를 전환하지만, 이 시안은 고정 폭 화면을 가로로 스크롤합니다.

OMP에서는 /skills가 스킬 관리를, /agents가 에이전트 설정을 열고, /hub는 실시간 Agent Hub를 엽니다. /mcp, /git, /settings, /hotkeys 등도 있지만 이 시안에서 모든 기능을 재현한 것은 아닙니다. 목록의 review-auth는 확인용으로 만든 예시 스킬이며 기본 제공 스킬이 아닙니다.

키 충돌: MindPlayer는 Ctrl+P를 HTML 미리보기에 쓰고, pane이 둘 이상이면 Shift+Tab을 pane 전환에 사용합니다. OMP의 대안인 Alt+M과 /effort를 이 시안에 사용했습니다. Ctrl+Q는 pane 닫기이며, Ctrl+Enter와 Ctrl+Shift+O도 PTY 전달 시 수정자가 구별되지 않습니다. 실제 통합 전에는 키 소유권과 터미널별 입력을 검증해야 합니다.
