먼저 Codex, 나중에 Claude

현재 MindPlayer는 입력 바이트를 PTY로 전달합니다. 완성된 프롬프트 수집과 턴별 모델 적용은 아직 없습니다. Enter 감지만 붙여서는 충분하지 않습니다.

Codex 턴 어댑터에서 모델 지정과 세션 유지를 검증해야 합니다. Claude는 나중에 같은 원칙의 별도 어댑터로 지원합니다. 자동 판정이 실패하면 기존 모델을 유지하는 정책을 제안합니다.

REA는 조사 도구

REA로 Jev 구조를 조사하고, 그 결과를 자체 판정기 설계에 활용합니다. REA 자체가 판정기가 되거나 매 입력 경로에 들어가는 것은 아닙니다.

TypeSafe의 비공개 구현을 확인했다는 뜻은 아닙니다. 실제 모델 목록·판정 정책·실패 처리는 구현 단계에서 검증해야 합니다.

왜 이렇게 줄였는지 · 근거 보기

기존 터미널의 분할·입력·하단을 그대로 두고, 선택한 창에만 짧은 표시를 붙였습니다. 별도 세션 목록, 상시 상세 패널, 통합 입력창은 추가하지 않습니다. 기존 Ctrl-G 기록 화면도 바꾸지 않습니다.

실제 코드에서 확인한 것

  • ui.rs: 4+3 분할, 창 제목, 전체 폭 사용량 하단, 중앙 팝업.
  • main.rs / app/pane.rs: 선택한 PTY에 입력 전달.
  • 제목의 자동/고정 표시는 새 제안입니다. 기존 앱의 모델 선택 기능이 아닙니다.

시안의 범위

  • 본문·계정·사용량·모델 이름은 모두 예시입니다.
  • HTML 클릭은 체험용입니다. 실제 TUI의 설정 진입 키는 아직 정하지 않았습니다.
  • 좁은 브라우저는 화면별 가로 스크롤로 4+3 구조를 보존합니다.
  • 외부 의존성 없는 HTML/CSS·자체 SVG를 선택했습니다. 정적 그래프 그림과 외부 그래프 라이브러리는 이 작은 시안에 필요하지 않습니다.
