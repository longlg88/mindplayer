범위: 2026-10-19의 반복 입력 요구를 반영한 비교 시안입니다. 같은 세션의 첫 입력·두 번째·세 번째 입력 모두 매번 다시 선택합니다. 5안 어디에도 시작/세션 기본값이나 이전 선택 상속이 없습니다. 이전 시작 시 한 번 선택 계약을 이 시안에서만 대체합니다. 실제 TUI·데스크톱 앱·설치본·계정·세션·프로바이더는 변경하지 않았습니다.

전송 계약 제안: 사용을 확정하면 표시한 동일 세션의 입력·문답·요약만 Jev/선택한 Gateway에 외부 전송합니다. 비밀·원본 도구 출력·파일 본문은 기본 제외하며 요약의 민감정보 제거도 별도 구현이 필요합니다. 미사용은 Jev 전송 없이 현재 native 모델·effort를 유지합니다. 제공자·계정·권한·도구 범위는 바꾸지 않습니다. 실제 전송·모델 호출 없이 합성 예시만 보여줍니다.

상태 계약: 02만 전송 키가 이번 선택+전송이며 다른 안은 선택만으로 전송하지 않습니다. 모든 안에서 새 입력은 미선택입니다. 03의 선택창도 매번 초기화됩니다. 취소는 초안을 보존하고 실패 시 자동 우회·재시도하지 않습니다. 판단 중/수락/실행/완료는 구분하며 실행 중 입력은 이 시안에서 보내지 않습니다. 미사용은 직전 Jev가 적용한 native 모델을 원래 모델로 되돌리는 기능이 아닙니다.

근거 1차: 기존 DESIGN.md와 기존 시작 설정표·4+3 갤러리. 2차: 기존 ui.rs / main.rs 팔레트·입력 키·footer, rubric.mjs의 history=[] / 8KB 제한과 service.mjs fallback 소비를 대조한 설계입니다. 맥락 전달 UI는 미구현이며 정확도를 보장하지 않습니다. 새 의존성은 없습니다. F6/F7/F8의 실제 CLI·OS/Fn·IME 충돌은 미검증입니다. 상단 버튼은 HTML 체험 도구이지 제품 위젯이 아닙니다.
