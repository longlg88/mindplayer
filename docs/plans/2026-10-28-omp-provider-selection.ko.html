세션 종류는 하나

기존 New session → omp 이후 OMP 안에서 고릅니다. MindPlayer에 Vercel 전용 세션을 추가하지 않습니다.

선택 범위는 명확하게

화면의 선택은 대화 모델을 나타냅니다. 보조 모델과 서브에이전트까지 같은 경로를 쓰는지는 별도 검증이 필요합니다.

모델명과 화면은 예시입니다. 실제 계정·키·모델 사용 가능 여부·가격은 조회하지 않았습니다. 클릭과 입력은 브라우저 안에서만 동작하며 어떤 요청도 전송하지 않습니다.

화면의 근거와 구현 범위

MindPlayer의 전체 화면 전환과 OMP pane 테두리, OMP 선택창 및 모델 전환 확장 API를 참고했습니다. OMP의 내장 /model 화면을 자동으로 연다는 뜻이 아니라, OMP 확장용 선택 UI를 활용하는 제안입니다. 선택·취소 후 실제 요청 차단과 재개 동작은 구현 및 검증이 필요합니다.
