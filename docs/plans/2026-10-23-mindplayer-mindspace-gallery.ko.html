비전퀘스트에서 가져오는 것과 새로 만드는 것

공식 Disney 자료에서 확인한 ‘여러 AI 인격이 내부 MindSpace에 함께 머무른다’는 발상을 가져왔습니다. 이 문서의 저택·아틀리에·기록관·관제실·정원과 인물·의상·색은 MindPlayer를 위한 새로운 디자인입니다. 작품의 캐릭터, 배우 외모, 로고나 정확한 세트를 재현하지 않았습니다. 인물 이름과 역할 느낌은 시각적 비유이며 provider의 실제 성격·능력·직무를 주장하지 않습니다.

현재 HTML이 하는 것

새 원화 5장을 서로 다른 UI 배치에 연결합니다. 선택/입력 필요/턴 완료/신호 지연/77개 페이지/빈 상태와 native 4+3·Trace 복귀를 합성 데이터로 체험합니다. 고해상도 삽화의 인물은 그림이므로 생성·취소·완료 때 실제로 움직이지 않습니다. 실제 적용 시 각각 분리된 에셋 또는 그래픽 씬이 필요합니다. 그림의 인원·자세로 실시간 상태를 추론하지 않습니다. 표시 UI의 상태·ID만 체험 데이터입니다.

기존 F6·네이티브 입력/승인·provider/계정 결합·4-top/3-bottom·전체 폭 quota를 유지하는 제안입니다. 오피스에서 방향키는 순서대로 선택하며 Enter는 실행 화면 합성 보기입니다. 새 오피스 진입 키는 미정이고, 오피스의 Ctrl-G 진입도 제안입니다. 네이티브 실행 화면의 단축키 표시는 보존 계약이지 이 HTML의 완전한 PTY 에뮬레이션이 아닙니다.

데이터·접근성·프라이버시

모든 사람 이름·세션·계정·이벤트·사용량은 합성입니다. 세션은 provider + 계정 + 실제 ID로 구분하며 같은 제목이어도 합치지 않습니다. 상태는 기호와 텍스트를 함께 표시하고 색만으로 구분하지 않습니다. 자동 애니메이션은 없습니다. 방향키/Enter/Esc/Tab으로 체험하며 Tab을 가두지 않습니다. 외부 API·저장·실제 세션·로그인·버전·설치는 변경하지 않습니다.

남은 확인

Gavin의 비공개 Slack 그림은 여전히 접근할 수 없어 직접 비교하지 못했습니다. ‘그 수준 이상’이라는 대조 결과를 주장하지 않습니다. 이 HTML은 브라우저 디자인 시안이고 실제 터미널의 고해상도 렌더링 검증이 아닙니다. 작은 브라우저는 비교 문서용 재배치일 뿐 TUI 최소 크기를 보장하지 않습니다.

원화는 기본 제공 image_gen으로 생성했습니다. 5개 원화의 전체 프롬프트. 외부 요청 없이 인접 에셋을 로드합니다. 기존 저해상도 시안은 비교 기록으로만 남기며 새 5안을 우선 검토합니다.
