한눈에 보는 5가지 배치색상만 바꾼 안이 아닌, 서로 다른 공간 구조


캐릭터 1명 = provider + 계정 + 세션 ID가 결합된 세션 1개. 같은 제목도 다른 자리. 움직임·완료 표시는 실행 성공의 증거가 아닙니다.


범위 · 터미널 구현 방식 · 참고 확인 상태
이 HTML에서 확인할 것
오피스는 기존 목록의 대체 보기입니다. 세션을 선택한 뒤 Enter하면 원래의 4+3 실행 pane으로 돌아갑니다. 이 문서의 실행·Trace는 합성 화면이며 명령을 실행하거나 세션을 시작하지 않습니다. 현재 제품에 오피스 기능을 추가한 것이 아닙니다. 위 버튼과 드롭다운은 HTML 비교 도구이지 Bash UI가 아닙니다.
표현 방식 3개 비교
방식장점제약 / 이번 판단
문자 셀 + ▀/▄ 반 블록기존 walker 렌더링 패턴 재사용. 터미널 문자 셀에서 컬러 픽셀을 표현.채택 제안. 픽셀 수·글자 폭 제약이 있어 작은 지도 + 텍스트 목록으로 분리. 실제 문자 셀 체험은 같은 그림의 상·하 픽셀을 전경/배경으로 변환.
터미널 이미지 프로토콜더 섬세한 그림·애니메이션 가능.호스트·프로토콜 지원과 폴백 검증 필요. 현재 안의 필수 조건으로 삼지 않음.
브라우저 / 데스크톱 SVG 오피스큰 화면·고해상도·마우스 상호작용에 유리.별도 제품 표면으로 범위가 커짐. 이번 제안에서는 별도 앱으로 바꾸지 않음.
기존 계약 보존
4-top / 3-bottom, 전체 폭 계정 quota, 네이티브 입력·승인·F6, Ctrl-G Trace와 계정 결합은 변경하지 않습니다. 지도 위치는 세션 키에 결합하고 상태가 바뀌어도 책상을 옮기지 않는 제안입니다. 77개 체험은 일부 책상만 표현하고 목록을 페이지로 탐색하며 숨겨진 세션 수를 밝힙니다. 미확인은 물음표와 갱신 지연으로 표시하며 0%나 대기로 바꾸지 않습니다. 턴 완료와 작업 성공은 다릅니다.

미결정 / 검증 경계
